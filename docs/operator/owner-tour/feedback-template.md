# AquaCrop owner tour: feedback

Copy this block once per finding. Give each finding your own number and put that number in the
comments of `owner-tour/results.html` (or the "Issue ID" column of `owner-checklist.csv`). F-01 to F-09
are taken by the first-time-operator review of 0.3.2 (`issues.md`), so new findings start at F-10; a
finding that comes back keeps its number. Keep passwords and e-mail addresses out of
the text and the screenshots.

The release version and source commit are on Settings, card Versions (row Release).
