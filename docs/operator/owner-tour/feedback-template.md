# AquaCrop owner tour: feedback

Copy this block once per finding. Give each finding your own number (F-01, F-02, …) and put that
number in the "Issue ID" column of `owner-checklist.csv`. Keep passwords and e-mail addresses out of
the text and the screenshots.

The release version and source commit are on Settings, card Versions (row Release).
