# ADR-0005 FC0F (write multiple coils) not implemented
Status: accepted

Context: the brief marks batch writes as optional, allowlisted, with no implied cross-device
transaction.
Decision: not implemented. Bench tests need one explicit output at a time with a readback each;
a batch adds failure modes (partial apply) without a current use.
Impact: acceptance items for FC0F are NOT RUN. The adapter exposes no multi-coil method.
